\# REQUIREMENT ANALYSIS

\## Project: Football Field Booking Application



\### 1. Overview

The Football Fsield Booking Application is a mobile application that allows users to search, view, and book football fields online by selecting date and time slots.  

The system helps field owners manage bookings and reduces manual scheduling conflicts.



---



\### 2. Actors

\- \*\*User\*\*: Normal user who books football fields.

\- \*\*Admin\*\*: Field owner or system administrator who manages fields and bookings.



---



\### 3. Functional Requirements



\#### 3.1 User Functions

\- Register a new account

\- Login / Logout

\- View list of available football fields

\- View field details (location, price, description)

\- Select date and time slot

\- Book a football field

\- View booking history

\- Cancel booking (before playing time)



\#### 3.2 Admin Functions

\- Login

\- Manage football fields (add / update / delete)

\- View all bookings

\- Update booking status (confirmed / canceled)



---



\### 4. Non-Functional Requirements

\- Mobile-friendly UI

\- Fast response time

\- Secure authentication

\- Data stored on server database (no hard-coded data)



---



\### 5. Business Rules

\- A time slot can only be booked by one user.

\- Users cannot book past time slots.

\- Booking status must be confirmed by admin.
